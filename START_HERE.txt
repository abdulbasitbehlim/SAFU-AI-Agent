SAFU PERSONAL AI 0.0.1 — START HERE
===================================

IMPORTANT: use a fresh folder
-----------------------------
Do not copy this build over an older assistant folder. Rename or remove the
old folder first, then extract this ZIP to a clean location such as:

    D:\Safu

Recommended Windows setup
-------------------------
1. Use 64-bit Python 3.11, 3.12, or 3.13. CPython is recommended; Anaconda is
   also supported as long as the active `python` command is one of these versions.
2. Open Command Prompt in the extracted Safu folder.
3. Run:

       run_safu.bat

4. On first launch Safu installs the standard/lightweight dependencies.
5. Enter your Gemini API key when Safu asks for it.
6. Say "Hey Safu". Setup attempts a matching PREBUILT PocketSphinx wheel and
   never source-builds it. If a supported local wheel cannot be installed, Safu
   still starts and can use its guarded connected wake fallback.
7. There is no separate wake-model or wake-voice download button.

Verify the installation
-----------------------
The ZIP was preflight-tested before packaging. After dependencies are installed
on YOUR Windows PC, run the stricter local check:

    python verify_safu.py --strict

or double-click:

    verify_safu.bat

A strict PASS verifies the required runtime packages on your machine in addition
to the source/config/security smoke tests.

Full/heavy feature mode
-----------------------
The standard install keeps storage and idle overhead lower. For browser DOM
automation, camera/vision, phone dashboard and optional integrations, run:

    python setup.py --full

This installs the heavy extras and Chromium. Then run:

    run_safu.bat

Voice
-----
The default Safu voice is Gemini Leda with an original warm, youthful and
expressive persona. No Naruto/Sakura Haruno recording, copied anime dialogue,
or cloned actor voice is included.

Useful tests after launch
-------------------------
- Put Safu to sleep, then say: "Hey Safu"
- Ask: "Find my thesis PDF on D drive and open it"
- Ask: "Give me my morning briefing"
- Drop a PDF/Word/Excel file into the Files area
- Open Control Center and test microphone/speaker selection
- Enable the phone dashboard only if you actually need LAN remote control

Troubleshooting
---------------
If the local Hey Safu engine is unavailable, run:

    FIX_WAKE_ERROR.bat

or:

    python setup.py

If startup fails, first run:

    python verify_safu.py --strict

The report tells you which runtime dependency is missing. Also read
SAFU_UPGRADE_NOTES.md, SECURITY_AUDIT.md and FINAL_VERIFICATION.txt.


SAFU 0.0.1 reliability check
----------------------------
On the first launch of this build, run_safu.bat automatically runs:

    python verify_safu.py --strict

This now includes a real hidden Qt MainWindow construction test in addition to
source compilation, callback-integrity and dependency checks. If it reports FAIL,
do not continue to main.py; copy the FAIL line when asking for help.

PYTHON 3.14+ NOTE
-----------------
SAFU 0.0.1 fixes a verifier false-positive where CPython's internal
__conditional_annotations__ symbol was reported as an undefined global.
This symbol is created by the Python 3.14+ compiler and is not a SAFU bug.
On Python 3.14+, PocketSphinx local wake may be unavailable; SAFU will use
the guarded cloud wake fallback instead. Python 3.11-3.13 remains preferred
for fully local PocketSphinx wake support.


LANGUAGE BEHAVIOR
-----------------
You may speak or type in any supported language. SAFU auto-detects and understands
the input, but SAFU's spoken and written replies stay in English. Leda remains the
default voice.

INSTANT REPLY MODE
------------------
This build enables Instant Reply mode by default. It uses a shorter Live-API
end-of-speech window, smaller microphone chunks, concise first responses, and
avoids unnecessary tool/web calls for ordinary conversation. Heavy web/file/code
tasks can still take longer because the external work itself must finish.

MULTI-MODEL + AUTOMATION (0.0.1)
--------------------------------
Open the Controls drawer and choose "MODEL BRAIN" to configure an optional
secondary brain. Safu can delegate heavy tasks to Gemini, OpenAI, Anthropic,
Ollama, or an OpenAI-compatible local server. Gemini Live remains the realtime
voice/orchestrator in this build.

Desktop file creation now uses Windows Explorer's real user-folder mapping, so
OneDrive-redirected desktops are supported. Try:

    Create a file called SafuTest.txt on my Desktop and write Hello from Safu.

For a Word file:

    Make a Word document called TestReport.docx on my Desktop with a heading
    Test Report and two short paragraphs.

For a multi-step test:

    Create a folder named SafuDemo on my Desktop, create notes.txt inside it,
    write Today's task list in the file, then open the folder.

Safu will not silently overwrite an existing document created by document_creator;
it chooses a duplicate-safe name such as "Report (1).docx".
